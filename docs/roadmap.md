# Roadmap v0.1

No dates committed. Completion requires evidence and owner acceptance.

| Milestone | Scope | Exit criterion |
|---|---|---|
| M0 — Foundation | specifications, governance, CI skeleton | owner-reviewed decisions and contracts |
| M1 — Studio | organization, brands, media, drafts, calendar | pilot can prepare and preview content |
| M2 — AI | BYO-key text/image/video/voice adapters, job cost tracking | approved sample outputs and failure tests |
| M3 — Publishing | Meta, LinkedIn, YouTube adapters, OAuth, scheduling | live authorized publication per supported channel |
| M4 — Insights | basic analytics and reporting | metrics reconcile with platform data |
| M5 — Community 1.0 | docs, security, installation, stable contracts | independent self-host installation and acceptance |

Commercial SaaS, autonomous campaigns and engagement inbox are future exploration, not MVP commitments.

# Google video generation — SYN-AI-005

Verified 2026-10-27 against Google's [Omni video guide](https://ai.google.dev/gemini-api/docs/omni),
[model card](https://ai.google.dev/gemini-api/docs/models/gemini-omni-flash),
[Interactions API](https://ai.google.dev/api/interactions-api),
[background execution](https://ai.google.dev/gemini-api/docs/background-execution)
and [pricing](https://ai.google.dev/gemini-api/docs/pricing).

`gemini-omni-1.1-flash` is the sole executable video model. This slice offers
one 720p MP4, 9:16 or 16:9, with short 3, 5 or 10 second requests. The model
card gives a 3–10 second output range; Interactions accepts a duration string.
Actual output duration and codecs are checked before preview. The model is
paid-tier only. A configured key or local access flag is not proof of entitlement.

## Execution and limits

The server creates one Google background Interaction with `store=true` and
`delivery=uri`, then persists the provider ID. Status reads retrieve that exact
interaction and, when complete, obtain output through the SDK's authenticated
interaction retrieval. No browser URL or arbitrary provider URI is fetched.
Google currently returns inline video data on interaction retrieval even when
URI delivery was requested. If it ceases to do so, the result fails safely
instead of following an unverified URL. No automatic paid retry, worker or Redis.

Generated bytes are limited to 20 MiB; source images to 10 MiB. Duration must
be within the model's 3–10 second range and at most the requested duration plus
a small container tolerance. MP4 validation uses the existing bounded ffprobe
path. Audio, when present, is preserved as AAC in the same MP4 and shown as
provenance. The output is AI-generated media, not authentic product footage.

The 720p Standard price references $1.50 per million input tokens and $17.50
per million video output tokens (approximately $0.10 per second before input
and other output). Input and output token usage can vary, so this is not a
reliable pre-request cap. A selected monthly USD limit remains fail-closed.

## Known limits

No paid Google video request or account-access proof is claimed from deterministic
tests. Google notes that non-English video results have not been evaluated.
Process loss before receiving an interaction ID leaves an uncertain record;
the application does not create a second paid request automatically. A process
crash between private file publication and database commit may leave an orphan.
Background interactions are stored by Google under its documented retention
rules. No editing, extension, subtitles, mixing, assembly or publication.

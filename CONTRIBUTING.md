# Contributing to SYNVARO

Thank you for considering a contribution. SYNVARO is an Apache-2.0 open-source AI content studio in early development.

## Before you start

- Read [README](README.md), [agent guidance](AGENTS.md), [product scope](docs/product.md) and [decisions](docs/decisions.md).
- Discuss substantial product or architecture changes in an issue before implementation.
- Small documentation fixes and narrowly scoped bug fixes are welcome.
- Do not claim planned features are already available.

## Development

Follow [docs/development.md](docs/development.md) for supported Node/pnpm versions, local setup and verification. No Docker is required.

## Pull requests

- Keep each PR focused; link the relevant issue or behavior/acceptance ID when available.
- Explain what changed, why, and how it was verified.
- Include tests for changed behavior. Distinguish mocked checks from live API verification.
- Run formatting, lint, typecheck, tests and build before requesting review.
- Do not commit secrets, tokens, customer data or real social account credentials.
- Do not alter accepted domain contracts without owner review.

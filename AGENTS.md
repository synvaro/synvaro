# AI Agent Instructions

1. Read README.md and docs/decisions.md; then only the relevant domain documents.
2. **Proposed is not Accepted.** Never silently promote a proposal to an architectural decision.
3. Do not claim planned capabilities are implemented or tested.
4. Implement only scoped behaviors with acceptance criteria; request clarification for gaps.
5. Link changes and tests to stable behavior IDs (e.g. PUB-001-A1).
6. No direct automatic publishing without approval for the exact content revision.
7. Never fabricate product facts, prices, discounts, inventory, or release status.
8. Do not store OAuth tokens or provider secrets in plaintext or commits.
9. Prefer a simple modular monolith; do not add microservices or an agent framework without an approved decision.
10. Record test evidence and limitations; distinguish mocks from live external API tests.
11. Do not change contracts or accepted decisions without explicit owner review.
